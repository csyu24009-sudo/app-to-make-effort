# app.py

Working in progress

## 1. 概要

多くの習慣化アプリはユーザーに「毎日休まず続けること」を求める。しかし、1日でも途切れるとモチベーションが急低下し、そのまま挫折してしまうことが課題であった。

本アプリケーションは、「3日続けたら1日強制的に休ませる」という逆転の発想を取り入れ、ユーザーにかかる心理的プレッシャーを軽減する。さらに、ゲーム感覚で楽しく長期的な努力の習慣化を達成することを目的とする。

---

## 2. 機能

### 今日のタスク完了チェック機能

- 1日1回、その日のタスク完了を報告する機能である。1つのタスクに対して、同日内の重複カウントは行えない仕様となっている。

### 進捗およびキャラクターの確認機能

- 現在の連続達成日数を画面上でいつでも確認できる。
- 画面上に相棒となるキャラクターが表示され、現在の状態に応じたメッセージでユーザーをサポートする。
- 3日連続達成した瞬間には、画面上で盛大な祝福演出が実行される。

### 強制ロック機能

- 3日連続でタスクを完了した翌日は、自動的に「お休み日」となる。
- お休み日の間は、ユーザーがタスク完了の操作を行えないよう、ボタンが強制的に無効化される。

### 日付判定およびデータの自動保存

- 報告が「昨日」から連続しているかを厳密に判定する。2日以上空いた場合は未達成とみなし、カウントを自動でリセットする。
- アプリケーションを終了しても状態が維持されるよう、ローカルのJSONファイルへ状態が自動的に保存・更新される。

## 3. 動作環境

本アプリケーションの動作には、以下の環境およびライブラリが必要である。

- 言語: Python 3.x
- Webフレームワーク: Streamlit
- データ保存: JSON（Python標準ライブラリ）

---

## 4. クイックスタート

### ステップ1: ライブラリのインストール

アプリケーションを実行するために必要な `Streamlit` を、以下のコマンドを用いてインストールする。

```bash
pip install streamlit
```

### ステップ2: アプリケーションの動作

カレントディレクトリで、以下のコマンドにより、アプリケーションを実行する。

```bash
streamlit run app.py
```
